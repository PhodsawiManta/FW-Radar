# Fastwork Jobboard Bot (Multi-Page + Date Filter + GPT Luna + Telegram Alert)

บอทตรวจจับงานใหม่บน [Fastwork Jobboard](https://jobboard.fastwork.co/jobs) แบบไล่หน้า (`?page=1, 2, 3, ...`) พร้อมกำหนดวันที่ต้องการดึงงานได้ (ค่าเริ่มต้นคือ **`today` = วันนี้**) ใช้ **GPT Luna (`gpt-6-luna`)** คัดกรองเฉพาะงานที่ตรงความต้องการ และแจ้งเตือนเข้า **Telegram** ทันที

## ฟีเจอร์หลัก
- **ไล่ดึงข้อมูลหลายหน้าอัตโนมัติ (`?page=1, 2, ...`)** และหยุดไล่หน้าอัตโนมัติเมื่อเจองานที่เก่ากว่าวันที่กำหนด ช่วยให้ทำงานเร็วและไม่เปลืองทรัพยากร
- **กำหนดวันที่ต้องการดึงงานได้อิสระ (`FASTWORK_TARGET_DATE`)**:
  - `today` หรือ `now` *(ค่าเริ่มต้น)* — เฉพาะงานที่ลงประกาศวันนี้ (ตามเวลาไทย UTC+7)
  - `yesterday` — งานเมื่อวาน
  - `3d`, `7d` — งานย้อนหลัง N วัน (เช่น 3 วันล่าสุด)
  - `22/10/2026` หรือ `2026-10-22` — ระบุวันที่เจาะจง
  - `20/10/2026-22/10/2026` หรือ `2026-10-20..2026-10-22` — ระบุช่วงวันที่
  - `all` — ดึงทุกวันตามจำนวนหน้าสูงสุด (`FASTWORK_MAX_PAGES`)
- **คัดกรองอัจฉริยะด้วย GPT Luna (`gpt-6-luna`)** แบ่ง Batch อัตโนมัติ ให้คะแนนความตรงใจ (`0-100`), สรุปเหตุผล และช่วยร่างข้อความเสนอรับงาน (`suggested_pitch`)
- **ฐานข้อมูล SQLite (`data/jobs.db`)** จดจำงานที่เคยตรวจแล้ว ไม่ส่งแจ้งเตือนซ้ำ
- **Interactive Telegram Bot** รองรับทั้งแชทส่วนตัว, กลุ่ม และ **Telegram Channel**

## การใช้งานผ่าน Terminal (CLI)

### 1. ทดสอบไล่หน้าดึงงานของวันนี้ (ค่าเริ่มต้น `today`)
```powershell
python main.py --test-fetch
```

### 2. ทดสอบระบุวันที่ หรือช่วงวันที่ และจำนวนหน้าสูงสุด
```powershell
# ดึงงานเฉพาะวันที่ 21/10/2026 โดยไล่ดูสูงสุด 10 หน้า
python main.py --test-fetch --date 21/10/2026 --max-pages 10

# ดึงงานย้อนหลัง 3 วันล่าสุด
python main.py --test-fetch --date 3d --max-pages 15

# ดึงงานช่วงวันที่ 20/10/2026 ถึง 22/10/2026 แล้วกรองด้วย GPT Luna ส่งเข้า Telegram ทันที 1 รอบ
python main.py --once --date 20/10/2026-22/10/2026
```

### 3. รันบอทตรวจจับงานต่อเนื่อง
```powershell
python main.py
```

## คำสั่งใน Telegram Bot / Channel
- `/start` หรือ `/help` — แสดงเมนูคำสั่งและดู Chat ID
- `/status` — ดูสถานะบอท วันที่ตั้งค่า จำนวนหน้า โมเดลที่ใช้ และสถิติงาน
- `/check` — สั่งไล่ดึงงานตามวันที่ตั้งไว้ (ค่าเริ่มต้นคือวันนี้) และวิเคราะห์ด้วย GPT Luna ทันที
- `/check <วันที่>` — สั่งดึงงานของวันที่ระบุแบบเฉพาะกิจ เช่น `/check 21/10/2026` หรือ `/check 3d`
- `/setdate <วันที่>` — เปลี่ยนค่าเริ่มต้นว่าจะดึงงานของวันไหน เช่น:
  - `/setdate today` (ค่าเริ่มต้น: วันนี้)
  - `/setdate yesterday` (เมื่อวาน)
  - `/setdate 3d` (ย้อนหลัง 3 วัน)
  - `/setdate 22/10/2026` (ระบุวัน)
  - `/setdate 20/10/2026-22/10/2026` (ระบุช่วงวัน)
- `/setpages <จำนวนหน้า>` — ตั้งจำนวนหน้าสูงสุดที่จะไล่ดึง เช่น `/setpages 10`
- `/recent` — ดู 5 งานล่าสุดที่ตรงเกณฑ์
- `/setfilter <เกณฑ์งาน>` — เปลี่ยนเกณฑ์งานที่ต้องการให้ GPT Luna คัดกรองทันที
- `/setmodel <ชื่อโมเดล>` — เปลี่ยนโมเดล เช่น `gpt-6-luna`
- `/setscore <0-100>` — ตั้งคะแนนความตรงใจขั้นต่ำ
- `/setinterval <วินาที>` — ตั้งความถี่ในการเช็คงานใหม่
- `/pause` / `/resume` — หยุดชั่วคราว / กลับมาทำงานต่อ
